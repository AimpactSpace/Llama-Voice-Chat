Getting Started with Llama Voice Chat

This page explains how to use the chat even if you are not a technical expert.

  1. Type a message: Use the text box on the main page to write anything you want to ask.
  2. Send an audio file: Click the file button to upload a recording in m4a, mp3 or wav format.
  3. Speak to Llama: Press the microphone button to start voice mode. When you are done talking, press it again.
  4. The assistant will reply on the screen. If your browser allows, it will also speak the answer aloud.

If you are ready to try it out, return to the main chat page.
